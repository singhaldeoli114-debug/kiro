# Beauty Serum

## Description
Serum product hero template with elegant gradient background, centered bottle with glow effect, and ingredient highlights listed below in pill-shaped chips.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Radial gradient glow centered behind the product bottle
- Product occupies central 400px width area
- Brand name at top center with wide letter spacing
- Headline and subheadline centered below the product
- Ingredient chips in a horizontal row near bottom
- Logo at bottom center (optional)

## Slots Available

### Text Slots
- brand-name (secondary) - Brand name at top
- headline (primary) - Product name
- subheadline (secondary) - Product tagline
- ingredient-1 (tertiary) - First ingredient chip
- ingredient-2 (tertiary) - Second ingredient chip
- ingredient-3 (tertiary) - Third ingredient chip
- ingredient-4 (tertiary) - Fourth ingredient chip

### Media Slots
- hero-product (required) - Serum bottle image
- logo (optional) - Brand logo
