# Now Hiring

## Description
Recruitment ad template with a bold job title in display font, company logo area, requirements displayed as checklist items with checkmark indicators, salary range, and a prominent "APPLY NOW" CTA button at the bottom.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Dark professional background with accent color top bar
- Company logo top-left, "WE'RE HIRING" label top-right
- Job title in extra-bold display font centered
- Company name below job title
- Requirements section with checkbox-style checklist items
- Salary range with label before the CTA
- Full-width APPLY NOW button at bottom
- Green accent for energetic, growth-oriented feel

## Slots Available

### Text Slots
- hiring-label (tertiary) - "WE'RE HIRING" label
- headline (primary) - Job title
- company-name (secondary) - Company name
- requirement-1 through requirement-4 (tertiary) - Checklist items
- salary (secondary) - Salary range
- cta (primary) - CTA button text

### Media Slots
- company-logo (required) - Company logo image

## Notes
- Checklist uses CSS pseudo-elements for checkmark indicators
- Dark background with accent green for tech/startup feel
- Top accent bar adds brand color
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
