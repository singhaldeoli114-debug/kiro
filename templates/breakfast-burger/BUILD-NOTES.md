# Breakfast Burger

## Description
Breakfast combo template with vertically stacked burger ingredients shown in exploded view (bun top, patty, cheese, egg, bun bottom), side items in compact grid, meal deal price, and warm brown/amber aesthetic.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Dark warm brown gradient background
- Subtle radial amber glow behind burger stack
- Vertical ingredient stack in center (5 layers)
- Each layer shows one ingredient (exploded view)
- 3 side items in rounded card slots below
- Price and "Meal Deal" label with strong amber accent
- Bold CTA button at bottom
- Logo centered at top

## Slots Available

### Text Slots
- headline (primary) - Main headline
- subheadline (secondary) - Deal type
- price (primary) - Meal deal price
- meal-deal (secondary) - Deal label
- cta (primary) - Call to action

### Media Slots
- bun-top (required) - Top bun image
- patty (required) - Patty/meat layer
- cheese (optional) - Cheese layer
- egg (optional) - Egg layer
- bun-bottom (required) - Bottom bun image
- side-1 through side-3 (optional) - Side items
- logo (optional) - Brand logo

- Exploded ingredient view is the distinctive composition
- Warm amber accent on dark brown for appetizing feel
- Side item cards provide combo meal context
