# Fresh Juice

## Description
Vibrant juice/product splash template with circular fruit arrangement around a central glass/bottle, colorful gradient background transitioning from orange to pink, and radially placed fruit elements creating dynamic composition.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Vibrant orange-to-pink gradient background
- Central glass/bottle hero as focal point
- 3 fruit elements arranged radially around center (circular positions)
- CSS circle decorations create tropical energy
- Headline at top with wide tracking
- Flavor name and price below center
- Rounded CTA at bottom
- Logo centered at top
