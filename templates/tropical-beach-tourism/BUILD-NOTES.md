# Tropical Beach Tourism

## Description
Travel destination template featuring a full-bleed beach imagery slot covering the entire canvas, a dark scrim overlay for readability, and elegant white text overlay with the destination name and price positioned in the bottom third. Ultra-minimal aesthetic.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Full-bleed photo covers entire 1080x1080 canvas
- Gradient scrim overlay (transparent top to dark bottom third)
- Destination name in large elegant serif/display font at bottom
- Price in clean sans-serif below destination name
- Minimal tagline above destination name
- Ultra-clean, almost no UI elements except text
- Optional subtle logo at bottom corner

## Slots Available

### Text Slots
- tagline (tertiary) - Small aspirational label
- destination (primary) - Destination name large
- price (secondary) - Price display
- dates (tertiary) - Travel dates

### Media Slots
- background (required) - Full-bleed beach/destination photo

## Notes
- Scrim uses CSS linear-gradient for text readability
- Ultra-minimal design with maximum whitespace
- Text positioned in bottom third only
- Elegant, premium travel brand feel
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
