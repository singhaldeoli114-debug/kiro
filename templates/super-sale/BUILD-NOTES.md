# Super Sale

## Description
Bold universal sale template with MASSIVE centered typography and starburst CSS rays radiating from the center. Designed for maximum visual impact during flash sales and clearance events.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Solid bold background color (red by default)
- 24 CSS rays radiating from center point using transform rotate
- Massive "SALE" text centered (200px font-size)
- Discount percentage in contrasting accent color
- Rounded corner burst decorations in corners
- CTA button with pill shape below
- Logo centered at top

## Slots Available

### Text Slots
- super-text (secondary) - Top label text (e.g., "SUPER")
- sale-text (primary) - Main sale word in huge type
- discount-amount (primary) - Discount percentage
- subheadline (secondary) - Supporting urgency message
- cta (primary) - Call to action button text

### Media Slots
- logo (optional) - Brand logo

## Notes
- Starburst effect achieved purely with CSS rotated divs
- Typography-dominant layout with no product image needed
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
