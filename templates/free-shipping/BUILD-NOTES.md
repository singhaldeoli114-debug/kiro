# Free Shipping

## Description
Free shipping promotional template with a centered delivery icon area, bold ribbon banner across the center, and clear promo code display below. Friendly and trust-building design with a subtle diagonal pattern background.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Light background with subtle 45-degree stripe pattern
- Circular icon area at top (for delivery/truck icon)
- Full-width ribbon banner with fold effects at center
- Content below ribbon: headline, subheadline, promo code badge, CTA
- Dashed border on promo code for "coupon" feel
- Logo safe zone at top-left

## Slots Available

### Text Slots
- ribbon-text (primary) - Ribbon banner text
- headline (primary) - Main headline
- subheadline (secondary) - Supporting message
- code (primary) - Promotional code
- validity (tertiary) - Valid dates
- cta (primary) - Call to action

### Media Slots
- icon-image (optional) - Delivery/truck icon
- logo (optional) - Brand logo
