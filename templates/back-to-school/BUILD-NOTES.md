# Back to School

## Description
Education campaign template with playful colored geometric shapes (circles, triangles, and squares via CSS), school supply icon areas, an energetic headline in a fun display font, and a discount/offer badge.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Warm playful background color (fef3c7 yellow)
- Multiple CSS geometric shapes scattered around canvas:
  - Large circles (orange, blue) partially off-canvas
  - Triangles created with CSS borders
  - Rotated squares for visual interest
- School supply image slots on the right side
- Bold fun headline with large font weight
- Discount/offer badge rotated slightly for playful energy
- CTA button with rounded pill shape at bottom
- Energetic, youthful, colorful aesthetic

## Slots Available

### Text Slots
- label (tertiary) - Category label
- headline (primary) - Main fun headline
- subheadline (secondary) - Supporting message
- offer (primary) - Discount/offer text
- cta (secondary) - Shop Now CTA

### Media Slots
- supply-1 (required) - School supply image 1
- supply-2 (optional) - School supply image 2

## Notes
- All geometric shapes are pure CSS (borders, border-radius, transforms)
- Playful color palette uses orange and blue accents
- Slightly rotated elements add energetic feel
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
