# Glasses Protection

## Description
A product benefit ad with split layout showing protection features for eyewear/sunglasses. Uses a left/right split to juxtapose the product with its key benefit points.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Vertical 50/50 split: left side is dark for product, right side is light for benefits
- Product image centered in the dark left panel
- Benefits listed with large numbered markers on the light right panel
- Header spans both panels at top for brand cohesion
- CTA positioned at bottom-center spanning the split

## Slots Available

### Text Slots

- headline (primary) - Main product headline
- benefit1-title (secondary) - First benefit title
- benefit1-desc (tertiary) - First benefit description
- benefit2-title (secondary) - Second benefit title
- benefit2-desc (tertiary) - Second benefit description
- benefit3-title (secondary) - Third benefit title

### Media Slots
- product (required) - Glasses product image
- logo (optional) - Brand logo

## Notes
- Split panel is the defining composition element
- Dark/light contrast between panels creates strong visual division
- Numbered benefits create scannable reading pattern
- Different from speaker (side-by-side) through use of dark/light contrast and numbered benefits instead of bullets
