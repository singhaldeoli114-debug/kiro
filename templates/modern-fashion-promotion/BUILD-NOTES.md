# Modern Fashion Promotion

## Description
An editorial cutout fashion ad with asymmetric model placement on a warm, neutral background. Features a large circular decorative shape and refined typography hierarchy.

## Layout Approach

- Large circular shape element positioned top-right for visual interest
- Model cutout positioned bottom-right, taking roughly 55% width
- Text content block anchored center-left with vertical centering
- Large faded promo tag at bottom-left for depth
