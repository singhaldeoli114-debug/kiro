# Summer Fashion Promotion

## Description
A seasonal campaign template with warm orange tones and a diagonal split layout. Bold clip-path diagonal creates an energetic composition for summer promotions and sales events.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Diagonal clip-path splits the canvas (45/55 ratio)
- Left panel uses --surfaceAlt as a warm color fill
- Model/product image on right side with rounded corners
- Text stacked vertically on the left with clear hierarchy
- Discount badge uses contrasting dark background
- CTA button uses pill shape with contrasting colors

## Slots Available

### Text Slots
- season-tag (tertiary) - Season/campaign label
- headline (primary) - Main large headline
- subheadline (secondary) - Supporting text
- discount (primary) - Discount badge text
- cta (primary) - Call to action button

### Media Slots
- model (required) - Main campaign imagery
- logo (optional) - Brand logo

## Notes
- Diagonal split is the defining compositional element
- Warm orange palette with contrast; all via CSS vars
- Rounded corners on the product image soften the diagonal
