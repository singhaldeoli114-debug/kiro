# Fast Food Promotion

## Description
Bold fast-food product offer template with energetic red/yellow palette, large hero food image dominating 60% of canvas, combo meal grid, price starburst badge, and strong call-to-action.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Bold red background with diagonal stripe pattern
- Large hero food image centered (60% of canvas)
- Price displayed in circular starburst badge (top-right)
- Combo items shown in rounded grid below hero
- "LIMITED TIME" badge top-right with slight rotation
- Strong yellow CTA button at bottom
- Logo top-left

## Slots Available

### Text Slots
- headline (primary) - Main offer headline
- product-name (primary) - Name of the product
- price (primary) - Price in starburst
- description (secondary) - Combo description
- cta (primary) - Call to action
- badge-text (secondary) - Promotional badge

### Media Slots
- hero-food (required) - Main food hero image
- side-item-1 (optional) - First side item
- side-item-2 (optional) - Second side item
- logo (optional) - Brand logo
