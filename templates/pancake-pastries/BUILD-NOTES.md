# Pancake Pastries

## Description
Dessert promotion template featuring a pancake stack visual created with stacked rounded rectangles (CSS shapes), syrup drip effect via narrow bars, topping chips listed in a row, warm brown/amber palette, and cozy indulgent feel.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Warm dark brown gradient background
- Radial amber glow overlay for warmth
- CSS pancake stack (5 elliptical layers with decreasing width)
- Syrup drip effect using thin rounded bars
- Product image overlaid on pancake stack
- Topping options as rounded pill chips in a row
- Price and CTA at bottom
- Logo centered at top

## Slots Available

### Text Slots
- headline (primary) - Main headline
- subheadline (secondary) - Product type
- topping-1 through topping-4 (secondary) - Topping names
- price (primary) - Price
- price-info (tertiary) - Price description
- cta (primary) - Call to action

### Media Slots
- pancake-image (required) - Main pancake stack image
- logo (optional) - Brand logo

## Notes
- Stacked rounded rectangles with border-radius: 180px/40px create pancake shapes
- Syrup drips use thin absolute-positioned bars with border-radius
- Warm browns (#78350f, #451a03) feel cozy and indulgent
- Zero JavaScript
- Fixed 1080x1080 canvas
