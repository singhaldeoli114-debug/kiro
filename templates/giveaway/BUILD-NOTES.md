# Giveaway

## Description
Social media giveaway/engagement template with a centered prize showcase in a golden circle frame, numbered entry steps (1-2-3) below, and celebratory confetti dot decorations. Designed for Instagram contest posts.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Bold purple background with confetti dot decorations
- "GIVEAWAY" label and headline at top center
- Prize image in golden circle frame at center
- Three numbered entry steps in a row (1: Follow, 2: Like, 3: Tag)
- CTA button and terms at bottom
- Logo at top-right

## Slots Available

### Text Slots
- giveaway-label (secondary) - "GIVEAWAY" label
- headline (primary) - Main headline
- step1-text (secondary) - Step 1 instruction
- step2-text (secondary) - Step 2 instruction
- step3-text (secondary) - Step 3 instruction
- cta (primary) - Call to action
- terms (tertiary) - End date and details

### Media Slots
- prize-image (required) - Prize product/item image
- logo (optional) - Brand logo

## Notes
- Golden circle frame highlights the prize
- Numbered steps use gold circles with contrasting text
- Confetti dots placed using absolute positioning
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
