# Sale Discount

## Description
General discount advertisement template with a large circle containing the percentage in the top half, a headline banner divider, and a 3-column product thumbnail grid below. Clear visual hierarchy from discount to products to CTA.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Top section (55%): Large circle with discount percentage
- Headline banner bar dividing top and bottom
- Bottom section (38%): 3-column product grid
- CTA button floating over bottom grid
- Logo centered at top
- Clean white background with subtle blush accent area

## Slots Available

### Text Slots
- percent-value (primary) - Large number in circle
- percent-label (secondary) - "% OFF" text
- headline (primary) - Sale title banner
- cta (primary) - Call to action button

### Media Slots
- product-1 (required) - First product thumbnail
- product-2 (required) - Second product thumbnail
- product-3 (required) - Third product thumbnail
- logo (optional) - Brand logo

## Notes
- Large circle creates bold focal point
- Product grid allows showcasing multiple products
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
