# Lemon Soda Promotion

## Description
Dynamic beverage splash template with liquid splash effects achieved through CSS border-radius morphing shapes, centered bottle/can hero, citrus circle decorations, and a vibrant green-to-teal gradient background.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Deep green gradient background for freshness
- Multiple splash shapes using warped border-radius (organic liquid feel)
- Centered bottle/can hero image as focal point
- Floating citrus circles as decorative elements
- Headline and subheadline top-left for dynamic diagonal read
- Price tag with rounded corners bottom-right
- Bold rounded CTA button at bottom center

## Slots Available

### Text Slots
- headline (primary) - Main product headline
- subheadline (secondary) - Product name
- tagline (secondary) - Supporting tagline
- price (primary) - Product price
- cta (primary) - Call to action

### Media Slots
- bottle (required) - Main bottle/can product image
- logo (optional) - Brand logo

## Notes
- Splash shapes use border-radius: 60% 40% 70% 30% / 40% 60% 30% 70% for organic liquid forms
- Green palette communicates freshness and citrus
- Multiple opacity levels create depth
- Zero JavaScript
- Fixed 1080x1080 canvas
