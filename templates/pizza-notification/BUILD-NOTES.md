# Pizza Notification

## Description
Pizza offer notification template with a large centered circular pizza image area, red checkered CSS pattern background, "HOT DEAL" badge ribbon, dashed circle border frame, and bold order CTA.

## Layout Approach
- Dark background with subtle checkered CSS pattern (red/black)
- Radial red glow behind center pizza
- Large dashed-border circle framing the pizza image (520px)
- "HOT DEAL" badge ribbon with arrow pointer at top-right
- Headline and subheadline above the pizza
- Price prominently displayed below pizza
- Delivery note and CTA at bottom
- Logo centered at top
