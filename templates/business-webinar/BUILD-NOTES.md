# Business Webinar

## Description
Webinar registration template featuring a speaker photo in a large circle on the left, topic headline prominently displayed, date/time in a styled badge, bullet points of what attendees will learn, and a "Register Now" CTA button.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Dark professional background with accent color bar on left edge
- Speaker photo in a large bordered circle center-left
- Speaker name below the photo circle
- Event type label (uppercase, small) above headline
- Topic headline large and bold on the right side
- Date/time in a styled badge with border
- Bullet points as a list with accent dot markers
- CTA button at bottom left of content area

## Slots Available

### Text Slots
- event-type (tertiary) - Event type label
- headline (primary) - Topic headline
- date (secondary) - Date and time
- speaker-name (secondary) - Speaker name
- bullet-1 through bullet-4 (tertiary) - Learning points
- cta (primary) - CTA button text

### Media Slots
- speaker-photo (required) - Speaker headshot

## Notes
- Uses dark surface for professional webinar feel
- Accent color used for bullet markers and badge border
- Speaker photo has accent border ring
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
