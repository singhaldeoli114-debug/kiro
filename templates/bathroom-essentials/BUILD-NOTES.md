# Bathroom Essentials

## Description
Lifestyle product set template with bathroom scene 2x2 grid layout, clean white/marble aesthetic.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Clean white canvas with subtle marble-like CSS pattern
- 2x2 product grid with rounded corners
- Each cell contains product image and label below
- Brand name at top-left with logo at top-right
- Headline and subheadline centered above the grid
- CTA button centered at bottom

## Slots Available

### Text Slots
- brand-name (secondary) - Brand name
- headline (primary) - Set title
- subheadline (secondary) - Tagline
- product1-name (tertiary) - Product 1 label
- product2-name (tertiary) - Product 2 label
- product3-name (tertiary) - Product 3 label
- product4-name (tertiary) - Product 4 label
- cta (primary) - CTA button text

### Media Slots

- product-2 (required) - Product 2 image

- product-4 (required) - Product 4 image
- logo (optional) - Brand logo
