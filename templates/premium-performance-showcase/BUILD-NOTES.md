# Premium Performance Showcase

## Description
A bold product showcase template featuring a hero product image with performance statistics overlay. Designed for tech and premium products that communicate measurable advantages through data points.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Hero product occupies the right 65% of the canvas
- Headline and subheadline anchored top-left
- Stats overlay in a 3-column grid at bottom-left
- CTA button positioned bottom-right
- Logo safe zone at top-left

## Slots Available

### Text Slots
- headline (primary) - Main headline text
- subheadline (secondary) - Supporting tagline
- stat1-value (primary) - First statistic value
- stat1-label (tertiary) - First statistic label
- stat2-value (primary) - Second statistic value
- stat2-label (tertiary) - Second statistic label
- stat3-value (primary) - Third statistic value
- stat3-label (tertiary) - Third statistic label
- cta (primary) - Call to action button text

### Media Slots
- hero-product (required) - Main product image
- logo (optional) - Brand logo

## Notes
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
- Stats overlay uses semi-transparent background for readability over any product image
