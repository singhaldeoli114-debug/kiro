# Pricing Table Packages

## Description
Service pricing tiers template featuring a 3-column comparison layout. The middle column is highlighted and elevated as the featured/recommended plan. Each tier displays its name, price, feature list, and CTA button.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Dark surface background for professional SaaS feel
- Three equal-width columns with subtle rounded cards
- Middle column uses accent color background and is scaled up 5%
- "Most Popular" badge on the featured tier
- Each tier: name, large price, period, feature list, CTA button
- Featured tier CTA inverts colors for emphasis
- No images needed - pure text/data layout

## Slots Available

### Text Slots
- headline (primary) - Section title
- tier1-name (secondary) - First tier name
- tier1-price (primary) - First tier price
- tier2-name (secondary) - Featured tier name
- tier2-price (primary) - Featured tier price
- tier3-name (secondary) - Third tier name
- tier3-price (primary) - Third tier price
- badge (tertiary) - Featured tier badge text

### Media Slots
- None (pure text/data layout)

## Notes
- No media slots needed for this layout
- Middle column uses scale transform and box-shadow for visual elevation
- Feature list items are semantic text elements
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
