# New Fashion Launch

## Description
A collection launch template with a multi-image grid layout. Showcases multiple products in a grid arrangement with bold headline, ideal for new collection drops and lookbook-style ads.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- 2x2 image grid in the right 60% of canvas
- Images have slightly different sizes for visual rhythm
- Left 40% holds headline, description, and CTA
- Large background text number for editorial depth
- Each image slot is independently editable for curated grid

## Slots Available

### Text Slots
- collection-tag (tertiary) - Collection identifier
- headline (primary) - Main collection headline
- description (secondary) - Collection description text
- cta (primary) - Call to action text
- year (tertiary) - Background year/number element

### Media Slots
- grid-image-1 (required) - Top-left grid image
- grid-image-2 (required) - Top-right grid image
- grid-image-3 (required) - Bottom-left grid image
- grid-image-4 (required) - Bottom-right grid image
- logo (optional) - Brand logo

## Notes
- Multi-image grid is the distinctive layout element
- Images use gap spacing and border-radius for modern feel
- Background year text provides depth without distraction
