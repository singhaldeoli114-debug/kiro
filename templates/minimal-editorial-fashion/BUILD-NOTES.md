# Minimal Editorial Fashion

## Description
A magazine-style minimal editorial fashion template with generous whitespace, centered model image, and ultra-thin headline that overlays the image using mix-blend-mode difference.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- White background with maximum whitespace
- Model image centered as a portrait-aspect frame (560x700)
- Large ultra-thin headline text centered with blend mode for layering
- Top center logo and category label
- Bottom subtitle and underlined CTA link
- Symmetrical and centered composition throughout

## Slots Available

### Text Slots
- category-label (tertiary) - Collection/category name
- headline (primary) - Large editorial headline
- subtitle (secondary) - Supporting description
- cta (primary) - Underlined call to action link

### Media Slots
- model (required) - Fashion editorial image
- logo (optional) - Brand logo

## Notes
- Mix-blend-mode difference on headline creates interesting visual effect over the model image
- Ultra-thin weight (100) on headline is intentionally editorial
- Symmetrical centered layout distinguishes this from other fashion templates
- Maximum whitespace is the key design element
