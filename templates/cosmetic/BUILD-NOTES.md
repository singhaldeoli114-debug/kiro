# Cosmetic Campaign

## Description
Cosmetics campaign template with multi-product editorial grid arrangement, color swatches strip at bottom, and warm sophisticated palette.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- 3-column product grid with featured product spanning 2 rows
- Headline centered at top with editorial serif feel
- Brand/collection name in header bar
- Color swatches strip at bottom-left for shade display
- CTA and logo at bottom in a horizontal arrangement

## Slots Available

### Text Slots
- brand-name (secondary) - Collection/brand name
- headline (primary) - Campaign headline
- subheadline (secondary) - Tagline
- cta (primary) - Call to action text

### Media Slots
- product-1 (required) - Featured product (spans 2 rows)
- product-2 (required) - Second product
- product-3 (required) - Third product
- logo (optional) - Brand logo

## Notes
- Editorial grid creates visual hierarchy with featured product
- Color swatches are CSS-only circles (customizable via variables)
- Warm neutral background suits beauty/cosmetics branding
- Zero JavaScript
- Fixed 1080x1080 canvas
