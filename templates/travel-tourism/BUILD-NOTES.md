# Travel Tourism

## Description
Travel package campaign template with a destination photo grid (2x2) at the top, package name headline, price per person, dates, included features list, and a "Book Now" CTA button.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- 2x2 photo grid in the top half showing 4 destination images
- Package name headline below the photo grid
- Price per person large and prominent
- Travel dates with clear label
- Included features listed in a structured horizontal layout
- "Book Now" CTA button full-width at bottom
- Warm adventure-focused color palette
- Distinct from tropical-beach: multiple photos, structured data, practical details

## Slots Available

### Text Slots
- package-name (primary) - Package/destination name
- price (primary) - Price per person
- dates (secondary) - Travel dates
- feature-1 through feature-4 (tertiary) - Included features
- cta (secondary) - Book now CTA

### Media Slots
- photo-1 through photo-4 (required) - Destination grid photos
