# Cake Bakery

## Description
Elegant bakery product hero template with ornate decorative border/frame, corner flourishes, centered cake showcase, script-style italic typography, warm cream background, and artisan premium aesthetic.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Warm cream/parchment background
- Ornate double border with rounded corners
- Corner flourish elements at all four corners
- Script-style italic headline via --font-display
- Centered cake showcase with subtle warm shadow
- Circular price badge at right
- Supporting tagline and CTA at bottom
- Logo at top center

## Slots Available

### Text Slots
- pre-headline (tertiary) - Category label
- headline (primary) - Main headline (script/italic style)
- subheadline (secondary) - Brand heritage line
- price (primary) - Starting price
- tagline (tertiary) - Supporting info
- cta (primary) - Call to action

### Media Slots
- cake-image (required) - Featured cake image
- logo (optional) - Brand logo

## Notes
- Ornate frame uses border + ::before pseudo-element for double line
- Corner flourishes are absolute-positioned elements with partial borders
- Script/italic font-style creates elegant bakery feel
- Zero JavaScript
- Fixed 1080x1080 canvas
