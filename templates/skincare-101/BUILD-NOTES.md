# Skincare 101

## Description
Educational skincare template with numbered steps layout (Step 1, 2, 3), clean infographic style with icon areas for each step.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Clean white/neutral infographic-style layout
- 3 horizontal step cards numbered 1, 2, 3
- Each step has a circular icon area, step number, title, and description
- Brand header with category badge
- Headline centered at top
- CTA at bottom center

- step1-desc (tertiary) - Step 1 description
- step2-title (primary) - Step 2 title
- step2-desc (tertiary) - Step 2 description
- step3-title (primary) - Step 3 title
- step3-desc (tertiary) - Step 3 description
