# Facial Serum

## Description
Premium serum campaign template with centered dropper bottle area, concentric golden circles radiating outward, luxury minimal typography.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Black canvas for dramatic luxury contrast
- 3 concentric golden ring borders radiating from center
- Radial golden glow behind product
- Product centered vertically
- Brand name at very top with wide letter-spacing
- Logo optional below brand name
- Product name and description below product area
- CTA with border-only style at bottom

## Slots Available

### Text Slots
- brand-name (secondary) - Luxury brand name
- headline (primary) - Product name
- subheadline (secondary) - Description
- cta (primary) - CTA text

### Media Slots
- hero-product (required) - Serum bottle
- logo (optional) - Brand logo

## Notes
- Concentric circles use CSS borders (no images)
- Ultra-minimal: only 4 text elements
- Accent line separator adds editorial refinement
- Dark-on-gold color scheme for maximum luxury
- Zero JavaScript
- Fixed 1080x1080 canvas
