# Headphone

## Description
A floating tech product template with radial background gradient and spec callouts. Designed for premium audio products with a dark tech-forward aesthetic and radiating energy from center.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Dark surface with radial gradient emanating from center
- Product floats at center with subtle shadow
- Concentric rings behind product for depth/energy
- Specs listed in corner columns (left and right)
- Product name headline above product
- Price and CTA at bottom center

## Slots Available

### Text Slots
- brand-tag (tertiary) - Brand label
- headline (primary) - Product name
- spec1-label (tertiary) - First spec label
- spec1-value (secondary) - First spec value
- spec2-label (tertiary) - Second spec label
- spec2-value (secondary) - Second spec value
- spec3-label (tertiary) - Third spec label
- spec3-value (secondary) - Third spec value
- price (primary) - Price display
- cta (primary) - Call to action

### Media Slots
- product (required) - Headphone product image
- logo (optional) - Brand logo

## Notes
- Radial background gradient is the signature layout element
- Concentric circles drawn with borders (not images)
- Specs displayed in two columns flanking the product
- Dark tech aesthetic with accent-colored highlights
