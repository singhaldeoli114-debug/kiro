# Client Testimonials

## Description
Testimonial/social proof template featuring large CSS quotation marks, centered avatar circle, 5-star rating row created purely with CSS clip-path, and a prominent quote text block with reviewer attribution.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Large decorative quotation marks via CSS (low opacity background element)
- Avatar photo in a bordered circle at top center
- 5 stars in a row using CSS clip-path polygon (no images)
- Testimonial quote text centered with generous padding
- Reviewer name and company below the quote
- Accent color bar at bottom edge
- Optional logo at bottom center

## Slots Available

### Text Slots
- testimonial (primary) - The quote/testimonial text
- reviewer-name (secondary) - Name and title of reviewer
- company (tertiary) - Company name

### Media Slots
- avatar (required) - Client photo in circle
- logo (optional) - Brand logo

## Notes
- Stars are pure CSS using clip-path polygon
- Quotation marks use CSS content, no images
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
