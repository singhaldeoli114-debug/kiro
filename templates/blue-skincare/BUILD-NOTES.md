# Blue Skincare

## Description
Clinical skincare template with cool blue monochrome palette, molecular dot pattern (CSS circles), and centered product image. Lab/clinical style.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Dark blue canvas background
- CSS molecular dot pattern scattered across canvas
- Thin connector lines for scientific/molecular feel
- Clinical badge with plus icon at top-left
- Product centered with blue radial glow
- Headline and subheadline above product
- Benefit statement below product
- CTA at bottom center

## Slots Available

### Text Slots
- badge-text (tertiary) - Clinical badge text
- headline (primary) - Product headline
- subheadline (secondary) - Formula description
- benefit (tertiary) - Clinical results statement
- cta (primary) - CTA button text

### Media Slots
- hero-product (required) - Product image
- logo (optional) - Brand logo

## Notes
- All dots and connector lines are pure CSS (no SVG/JS)
- Monochrome blue color scheme throughout
- Clinical/lab aesthetic differentiates from warm beauty templates
- Zero JavaScript
- Fixed 1080x1080 canvas
