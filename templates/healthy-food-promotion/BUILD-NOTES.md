# Healthy Food Promotion

## Description
Clean and fresh healthy meal campaign template with a white/green palette, circular salad bowl hero, 4-item ingredient grid with calorie badges, nutritional benefit info, and modern typography.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Clean white background with green accents
- Thin green accent bar at top
- Headline with green accent word for emphasis
- Large circular bowl area in center with soft green shadow
- 4-column ingredient grid below with calorie info
- Nutritional benefits row (calories, protein, fiber)
- Green rounded CTA button at bottom

## Slots Available

### Text Slots
- headline (primary) - Main headline
- subheadline (secondary) - Supporting text
- ingredient-1-name (secondary) - First ingredient name
- ingredient-2-name (secondary) - Second ingredient name
- ingredient-3-name (secondary) - Third ingredient name
- ingredient-4-name (secondary) - Fourth ingredient name
- cta (primary) - Call to action

### Media Slots
- hero-bowl (required) - Main salad bowl image
- ingredient-1 through ingredient-4 (optional) - Ingredient images
- logo (optional) - Brand logo
