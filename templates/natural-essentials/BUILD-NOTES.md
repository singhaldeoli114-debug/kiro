# Natural Essentials

## Description
Natural product collection template with botanical/organic aesthetic, leaf-like CSS shapes, earthy warm palette, and multiple product slots in an asymmetric arrangement.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Warm earthy canvas background
- CSS clip-path leaf shapes as decorative elements
- 3 product slots in asymmetric grid arrangement
- Headline at top center with organic serif feel
- Badge (100% ORGANIC) in top-right corner
- Product names below each product
- CTA centered at bottom

## Slots Available

### Text Slots
- headline (primary) - Collection title
- subheadline (secondary) - Tagline
- product1-name (tertiary) - Product 1 label
- product2-name (tertiary) - Product 2 label
- product3-name (tertiary) - Product 3 label
- badge (secondary) - Organic/natural badge text
- cta (primary) - CTA button text

### Media Slots
- product-1 (required) - First product image
- product-2 (required) - Second product image
- product-3 (required) - Third product image
- logo (optional) - Brand logo

## Notes
- Leaf shapes use CSS clip-path for botanical feel
- Asymmetric layout avoids rigid grid symmetry
- Warm earth tones throughout
- Zero JavaScript
- Fixed 1080x1080 canvas
