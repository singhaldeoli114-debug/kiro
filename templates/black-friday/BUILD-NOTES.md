# Black Friday

## Description
Dark luxury Black Friday campaign template with pure black background, gold accent lines and borders, and minimal premium composition. The centered vertical layout emphasizes the exclusive feel.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Pure black background with gold accent border frame
- Centered vertical layout for maximum impact
- Horizontal gold rule lines above and below discount text
- Large "BLACK FRIDAY" headline as focal point
- Optional product image area below headline
- CTA button with gold border style
- Logo at top center

## Slots Available

### Text Slots
- headline (primary) - Main event name
- subheadline (secondary) - Supporting qualifier
- discount-value (primary) - Discount amount
- date-text (secondary) - Event dates
- cta (primary) - Call to action
- terms (tertiary) - Terms and conditions

### Media Slots
- product-image (optional) - Featured product
- logo (optional) - Brand logo
