# Elegant Relaxation Therapy

## Description
Wellness/spa service template with calming lavender tones, spa imagery slot, horizontal service list, and soft typography.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Top 40% is spa imagery with lavender gradient scrim overlay
- Logo at top-left over the image
- Category badge at top-right
- Content section in bottom 60% with centered alignment
- Headline in elegant serif-weight display font
- Services displayed as horizontal pill-shaped badges with dot separators
- Round CTA button at bottom

## Slots Available

### Text Slots
- category (tertiary) - Category label badge
- headline (primary) - Main headline
- subheadline (secondary) - Description text
- service-1 (primary) - First service
- service-2 (primary) - Second service
- service-3 (primary) - Third service
- cta (primary) - CTA button text

### Media Slots

- logo (optional) - Brand logo
