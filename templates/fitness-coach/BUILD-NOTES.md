# Fitness Coach

## Description
Coach/service lead ad template with large trainer photo area (top 60%), service/speciality list below, bold motivational headline.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Photo takes top 60% height of canvas with dark gradient scrim
- Bold motivational headline overlaid at top-left of photo
- Logo at top-left corner over image
- Bottom 40% contains coach info and services
- Coach name and title left-aligned
- 2x2 service grid with accent indicators
- CTA button at bottom-right

- coach-title (secondary) - Certification/title
- service-1 (tertiary) - Service/speciality 1
- service-2 (tertiary) - Service/speciality 2

- service-4 (tertiary) - Service/speciality 4

### Media Slots

- logo (optional) - Brand logo
