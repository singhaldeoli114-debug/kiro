# New Arrival

## Description
New-arrival campaign template with a spotlight/beam effect from above that illuminates the centered product. Features a prominent "NEW" badge in the top-left corner and dark background for dramatic contrast.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Dark background with CSS triangle beam from top center
- Radial gradient glow behind product area
- Product centered and hero-sized with green-tinted drop shadow
- "NEW" badge in bright accent color at top-left
- Content anchored to bottom: eyebrow, headline, subheadline, price, CTA
- Logo at top-right

## Slots Available

### Text Slots
- new-badge (primary) - "NEW" corner badge
- eyebrow (secondary) - Category/timing text
- headline (primary) - Product name
- subheadline (secondary) - Description
- price (primary) - Product price
- price-note (tertiary) - Price context
- cta (primary) - Call to action

### Media Slots
- product-image (required) - Main product shot
- logo (optional) - Brand logo

## Notes
- Spotlight beam created with CSS border-triangle technique
- Radial gradient adds soft glow behind product
- Green accent suggests freshness/newness
- All colors use semantic CSS variables only
- Zero JavaScript
- Fixed 1080x1080 canvas
