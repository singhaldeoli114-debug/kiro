# Phone

## Description
A smartphone launch template with a gradient backdrop, centered device image, and feature highlight chips. Premium dark tech aesthetic with glowing accent orb for depth.

## Reference Fidelity
**inferred** - Built from description without CDN reference image.

## Layout Approach
- Deep gradient background (dark purple/navy) flowing diagonally
- Glowing accent orb behind phone for depth
- Phone positioned right, full height
- Left content area: launch tag, headline, subtitle, feature chips, price, CTA
- Feature chips use glass-morphism style (semi-transparent with border)
- Pill-shaped launch tag with accent background

## Slots Available

### Text Slots
- launch-tag (tertiary) - Launch identifier
- headline (primary) - Device name
- subtitle (secondary) - Marketing tagline
- feature1-3 (secondary) - Feature chips
- price (primary) - Starting price
- cta (primary) - Call to action button

### Media Slots
- phone (required) - Phone product image
- logo (optional) - Brand logo

## Notes
- Gradient is the signature background element (differs from radial in headphone template)
- Feature chips use subtle border and background for glass-morphism effect
- Glow orb adds depth without dominating
- Distinct from headphone template through left-aligned text + right product layout
